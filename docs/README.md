# Design notes
Keep decisions short and current. The canonical scope describes the eventual game; `next-slice.md` defines the management increment and `scene.md` defines the scene contract.

`next-slice.md` records the accepted management direction, interface contract, terrain expansion, tax ledger, contractor work lifecycle and visual guidelines.

`economy.md` documents current financial and contractor rules. `abi.md` describes the browser/Zig interface. `first-slice.md` is retained as historical context, not current mechanics.
